# java-learning-app

Spring Boot製のシンプルなブログアプリです。記事の投稿・編集・削除、コメントの投稿・削除ができます。

## 前提環境

- JDK 17

## 起動方法

```
./mvnw spring-boot:run
```

起動後 http://localhost:8080 にアクセスしてください。
